# Awdhesh Sahani - Personal Portfolio

A modern and responsive personal portfolio website built to showcase my skills, projects, certificates, resume, and contact information.

## 🌐 Live Demo

**Portfolio:** https://awdheshportfolio.vercel.app/

## 👨‍💻 About Me

Hi, I'm **Awdhesh Sahani**, a Computer Science Engineering student with an interest in web development and software development.

This portfolio website contains information about my technical skills, projects, education, certificates, resume, and contact details.

## 🚀 Features

- Responsive portfolio design
- About Me section
- Technical Skills
- Projects showcase
- Education details
- Certificates section
- Resume download
- Contact form
- Email notification using Resend
- Vercel Serverless Function
- Mobile responsive design

### Frontend

###  API
- Vercel Serverless Functions
- Resend API

- Vercel
- GitHub
